# apk-rebrand：APK 改名换图标

替换一个 APK 在手机“设置 → 应用”和桌面中显示的**应用名称**和**图标**，并在修改前检查名称和图标是否合理、给出修改建议。图标可以是 PNG / JPG / WebP / GIF / BMP 等常见图片，会自动转换成 APK 需要的格式。

## 下载

**[apk-rebrand-1.0.0.apk](https://github.com/lv2046/public/raw/main/apk-rebrand-1.0.0.apk)**（约 1.1 MB，Android 8.0 及以上，面向 Android 12）

SHA-256：`1eb45b93572d9d206f0a9219f3a6639972ffceba5117d8ee1be97cd4cc87c9fd`

手机上请用浏览器打开上面的链接下载，下载后点开文件，按提示允许“安装未知应用”。

## 使用

1. 打开 App，点“选择 APK 文件”，选中要修改的 APK。
2. 填写新的应用名称，和/或点“选择图片”选一张新图标。两项至少填一项。
   - 输入时会显示检查结果：错误（红色）必须改，警告和提示只供参考。名称有问题时可以一键采用建议的名称。
   - 选了图片后可以预览在 Android 12 上的显示效果，并调整图标样式、裁剪方式和背景色。
3. 点“生成新 APK”。
4. 点“安装”，或点“保存到…”把新 APK 存到手机里。

## 注意

- **这个 App 还没有在真机或模拟器上运行过**，只完成了编译、打包、签名和静态检查。它的核心逻辑与同一项目的命令行工具相同，后者通过了自动化测试，输出的 APK 用 Android SDK 的 aapt2、apksigner、zipalign 检查通过。
- 修改后的 APK 会被重新签名，签名与原版不同：
  - 要先卸载原版才能安装，原版的数据会被清除，之后也不能通过官方渠道升级；
  - 依赖签名校验的功能（第三方登录、支付、加固或自校验的应用）可能失效。
- 新名称对所有语言生效；应用内部用到旧名称、旧图标的地方（例如“关于”页面）不会变。
- 不支持拆分安装包（XAPK / APKS / AAB），只支持单个 APK。
- 请只修改你有权修改的应用。
